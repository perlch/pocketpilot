# Исследование и разработка мобильного ПО на базе Apache Cordova

Репозиторий содержит материалы проекта по созданию кроссплатформенного мобильного приложения с использованием веб-стека. Основной фокус сделан на минимизации ресурсов при разработке и обеспечении стабильной работы на маломощных аппаратных платформах.

## Технологический стек
*   **Core:** HTML5, CSS3, JavaScript (ES6+).
*   **Framework:** Apache Cordova.
*   **Build Tools:** Android SDK, Cordova CLI, Android Debug Bridge (ADB).
*   **IDE:** Sublime Text.
*   **Environment:** AntiX Linux (работа проводилась с 2 ГБ ОЗУ).

## Функциональные возможности
*   **Hardware Access:** Прямое взаимодействие с аппаратными функциями устройства через систему браузера.
*   **System Monitoring:** Вывод данных об использовании RAM, загрузке CPU (количество ядер) и состоянии аккумулятора в реальном времени.
*   **Network Module:** Определение типа соединения, статуса сети и замера задержки (ICMP/HTTP Ping).
*   **3D Engine:** Поддержка рендеринга трехмерных объектов, экспортированных из внешних сред (Blender, Maya, Autodesk).
*   **External DB:** Реализация обмена данными с удаленными БД.

## Архитектура процесса
1.  **Environment Setup:** Развертывание легковесной среды разработки для ускорения цикла сборки.
2.  **UI/UX Development:** Верстка адаптивного интерфейса по стандартам HTML5/CSS3.
3.  **Logic Implementation:** Написание логики на JavaScript, конфигурация Webview и Native API.
4.  **Compilation:** Сборка проекта в формат APK через консольный интерфейс.
5.  **Deployment:** Деплой и отладка на целевом устройстве через ADB.

## Планы на будущее
*   **Performance:** Интеграция Vue.js / React для оптимизации рендеринга.
*   **Native Features:** Добавление поддержки Push-уведомлений, биометрии и SQLite.
*   **Distribution:** Адаптация и публикация в локальных сторах (RuStore).
